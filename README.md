# Тест эмоционального интеллекта (ЭмИн Люсина)

Академия АНИНОТ. Мини-приложение Telegram: человек нажимает кнопку
в посте канала, тест открывается внутри Telegram, баллы считаются
сами, ник и результат падают в базу, а вам в Telegram приходит
уведомление.

## Файлы

```
emin/
├── index.html      экраны: вступление, 46 вопросов, результат
├── core.js         вопросы, ключ, нормы, тексты. Источник правды
├── config.js       адрес базы, ключ, кнопка в конце. Правится руками
├── core.test.js    сверка ключа с бланком: node core.test.js
└── server/
    ├── schema.sql                 таблица emin_results и вид emin_people
    ├── setup.sh                   разворачивание функции
    └── functions/emin-submit/     приём результата и уведомление
```

## Запуск

Всё делается в один день. Используется проект Supabase «Карты мышления».

**1. Таблица.** Supabase → SQL Editor → вставить `server/schema.sql`
целиком → Run.

**2. Сайт.** Залить папку `emin` на Vercel отдельным проектом
(`npx vercel --prod` из этой папки, или перетащить папку в vercel.com/new).
Получится адрес вида `https://emin-xxx.vercel.app`.

**3. Бот и мини-приложение.** У @BotFather:
- `/newapp` → выбрать бота Академии → название «Эмоциональный интеллект»,
  описание, картинка 640×360 → адрес сайта из шага 2 → короткое имя,
  например `emin`.
- В итоге ссылка на тест: `https://t.me/ИМЯ_БОТА/emin`.

**4. Функция.** Из папки `emin`:

```bash
bash server/setup.sh
```

Скрипт спросит адрес сайта, токен бота и id чата для уведомлений.
Id своего чата можно узнать у @userinfobot. Чтобы бот мог писать вам,
сначала откройте бота и нажмите «Старт». Для уведомлений в общий чат
команды добавьте бота в группу; id группы начинается с минуса.

**5. Ключ.** В `config.js` вставить публичный ключ из Settings → API,
ссылку для кнопки в конце результата и ссылку на сам тест
(`shareUrl`, для кнопки «Отправить тест другу»). Залить сайт ещё раз.

## Как устроен интерактив

Пока человек отвечает, за вопросами проявляется его «эмоциональный
отпечаток»: пять лепестков, по одному на субшкалу. Длина лепестка
считается от норм Люсина, пунктирное кольцо это средний уровень.
На 12, 23 и 36 ответах контрольные точки, где фигура видна яснее.
В результате: тип по карте (Дирижёр, Эмпат, Автономный, Автопилот,
Равновесие), общий балл, расшифровка каждого лепестка по нажатию,
карта «вы сами × другие люди». Тип пишется в колонку `ptype`.

## Пост в канале

Кнопки-«мини-приложения» в каналах не работают, работает обычная
кнопка-ссылка на `https://t.me/ИМЯ_БОТА/emin`. Её можно поставить
в текст поста или кнопкой через бота-постера (например, @ControllerBot).

Чтобы видеть, какой пост привёл человека, добавьте метку:
`https://t.me/ИМЯ_БОТА/emin?startapp=post_2610`. Она запишется в
колонку `start_param`. Разрешены латиница, цифры, `_` и `-`.

## Где смотреть результаты

- Supabase → Table Editor → `emin_people`: последний результат
  каждого человека, ник, имя, уровень, точка роста, число попыток.
  Кнопка Export → CSV открывается в Excel.
- `emin_results`: все прохождения со всеми 46 ответами.
- Уведомления в Telegram по каждому прохождению, если задан чат.

Колонка `verified`: `true` значит, что ник прислал сам Telegram и
подделать его нельзя. `false` бывает, если тест открыли обычной
ссылкой в браузере: тогда человек вписывает ник сам.

Ника может не быть: у части людей в Telegram он не заведён. Тогда
остаются имя и `tg_id`, по которому можно написать через бота.

## Персональные данные

Сохраняются ник и имя, это персональные данные по 152-ФЗ. На
вступлении стоит строка согласия; ссылку на политику вставьте
в `config.js` → `policyUrl`. Вопрос размещения базы за границей тот же,
что у «Карты мышления» (см. её `server/README.md`).

## Правки

Тексты результата, вопросы и нормы правятся в `core.js`. После правки
запустить `node core.test.js` и `bash server/setup.sh`, чтобы функция
считала по тому же ключу.
